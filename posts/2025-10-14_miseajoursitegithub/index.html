Update site github

Posted on Oct 14, 2025
tl;dr: git clone ; git commit ; git push

J’avais oublié que GitHub propose un système de site perso hébergé par eux. Le mien se trouve à ce lien : anselmatus.github.io

Dans le passé, j’avais testé les fonctionnalités et c’est plutôt pas mal sur le principe.

Il est facilement possible de trouver plein de ressources sur internet pour “hacker” cette fonctionnalité et faire afficher plein de choses.

Ce n’est pas ce que j’ai souhaité faire, du coup j’ai juste dupliqué mon site perso principal (mtwabp.fr).

J’ai donc supprimé tout ce qu’il y avait avant et j’ai remplacé par ce site. Un petit git push et c’est fait !
